# Prompt and asset guidance

Before generating, search a configured asset library or project references, if available. Use user-specified characters or established defaults; if no character is specified, design one consistent with the story. Record source, intended role, identity, pose/view, version, transparency, usage rights and quality status where useful. Never publish private source files or media with unclear authorization.

For each key visual or shot, prepare a prompt that states:

- Story beat, setting and emotional intent; relevant lyric and time range.
- Subject identity and reference, costume, visible features and continuity constraints.
- A specific action with start, middle and end; interaction, contact and gaze where relevant.
- Shot size, camera position or movement, composition, lighting and palette.
- Desired style and technique, aspect ratio, duration if supported, and any explicit exclusions.

Use negative constraints only when the selected generator supports them. Adjust language for the generator rather than claiming that text alone guarantees a result. Check generated images for white hair lost to transparency, unintended character changes, cut limbs, drifting details, expression mismatch, text errors and visible cutout seams. Independently review generated video for flicker, eye artifacts, inconsistent anatomy and motion. Do not treat a reference image as evidence that the corresponding animation is complete.

Keep reusable assets indexed with clear categories and descriptions when requested; preserve original media and avoid unverified external reuse rights. Store prompts and seed/settings if available so another agent can reproduce or revise the work.
