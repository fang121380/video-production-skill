# Tool and skill routing

Discover available skills and inspect the relevant instructions before use. Choose based on the user's task and actual capabilities, not on brand names alone.

| Need | Possible routes | Verify |
|---|---|---|
| HTML timeline, graphics, titles and captions | HyperFrames or equivalent | installation, render and preview capabilities |
| React timeline and compositing | Remotion or equivalent | installed runtime, render and media support |
| Realistic or animated clips from prompts | An available video-generation model or service | access, duration, resolution, privacy, quota and cost |
| Clip existing long footage | An available clip-editing service or local editor | whether it supports the actual requested operation |
| Inspect or transcode audio/video | FFmpeg or equivalent | codec, duration, frame rate and stream metadata |
| Transcribe or align captions | available speech recognition and alignment tools | language, confidence, lyric text and timing |

A tool name supplied by a user may refer to a skill or a service; inspect actual availability and ask only when the identity materially affects execution. A timeline renderer, still-image generator and video-generation model have different capabilities. Never invent installation, authentication or render success. Do not automatically upload private media or initiate paid usage. If a capability is missing, document it and choose an approved alternative where possible; do not substitute a static slideshow for requested character performance without telling the user.
